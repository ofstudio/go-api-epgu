## Примечание

Предназначено для демонстрации. Реализована только личная подача заявления
о доставке пенсии через российский банк из реестра СФР.
Почта, представители, МСЗ, иностранные банки и доставка до заключения договора не реализованы.
Проверки на полноту и валидность данных отсутствуют; выбор ТОСФР и банка обеспечивает вызывающий код.

**В поле `/ЭДСФР/ЗИРД/ТОСФР/УТ:Код` необходимо передавать трехзначный код
территориального органа СФР**, например `210` для Татарстана. Шестизначный код подразделения, например `210504`, вызывает ошибку:

> Ошибки при валидации блока 'Служебная информация': Обязательно к заполнению одно из полей: идентификатор сотрудника в
> метаданных запроса (userId) или Код территориального подразделения

Транспортный конверт использует пространства имен `urn://iis.ecp.ru/zird/1.0.2`
и `urn://iis.ecp.ru/zird/types/1.0.2`.
Версия `1.0.0` в исходной спецификации является подтвержденной ошибкой;
правильная версия транспортного формата — `1.0.2`.

Указанный в [спецификации v1.0 от 22.10.2026](doc/Specifikaciya_API_EPGU_Prilozhenie_60013502_Dostavka_pensii_v1.0.docx)
элемент `RegNum` является подтвержденной разработчиком опечаткой:
вместо него передается `SNILS` — 11 цифр СНИЛС заявителя из основного заявления.

Для `FRGUTargetId` используется `364359127` из таблицы 4.2.
